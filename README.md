# APK DUIT RAPIH

Folder ini disiapkan untuk tahap packaging Android setelah versi GitHub Pages + Google Sheets API diuji.

Untuk distribusi Google Play, gunakan Android App Bundle (AAB). Untuk instalasi langsung ke HP, APK release dapat dibuat dari proyek Android/Capacitor setelah URL web final sudah aktif.

Target Android/Play harus mengikuti persyaratan SDK yang berlaku saat publikasi.
